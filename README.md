Customer Shopping Behavior Analysis
An end-to-end data analytics project exploring customer shopping
behavior using Python, PostgreSQL, SQL, and Power BI. The project
covers data cleaning and preparation, database loading, business-focused
SQL analysis, and dashboard-based reporting.
Project Overview
This project uses a customer shopping behavior dataset containing
3,900 records and 18 original columns. It includes customer
demographics, purchased products and categories, purchase amounts,
discounts, subscriptions, shipping methods, reviews, and purchase
frequency.

The goal is to prepare the data for analysis and investigate customer
spending patterns, product performance, discount usage, subscription
behavior, and customer segments.

Project Workflow
1. Load and inspect the dataset
   - Read the CSV file with Pandas.
   - Review the first records, data types, descriptive statistics,
     and missing values.
2. Clean and prepare the data
   - Fill missing review ratings using the median review rating
     within each product category.
   - Standardize column names.
   - Rename the purchase amount field for easier querying.
   - Create age groups using quartile-based binning.
   - Convert purchase-frequency labels into an approximate number of
     days.
   - Remove the promo-code field after checking it against the
     discount-applied field.
3. Load data into PostgreSQL
   - Connect to PostgreSQL using SQLAlchemy and psycopg2.
   - Load the prepared DataFrame into a table named customer.
4. Perform SQL analysis
   - Use aggregations, filtering, subqueries, CASE expressions,
     CTEs, and window functions to investigate business questions.
5. Build a Power BI dashboard
   - Use the included Power BI report (customer_behavior.pbix) to
     present the analysis visually.
Business Questions
The SQL analysis explores the following questions:
1. What is the total revenue generated by male and female customers?
2. Which customers used a discount but still spent at least the average
   purchase amount?
3. Which five products have the highest average review ratings?
4. How do average purchase amounts compare between Standard and Express
   shipping?
5. Do subscribed customers spend more? Compare customer counts, average
   spend, and total revenue.
6. Which five products have the highest percentage of purchases with
   discounts applied?
7. How many customers fall into the New, Returning, and Loyal segments
   based on previous purchases?
8. What are the top three most purchased products within each category?
9. Among customers with more than five previous purchases, how many are
   subscribers versus non-subscribers?
10. What is the revenue contribution of each age group?

How to Run the Project
1. Clone the repository
git clone <your-repository-url>
cd <your-repository-folder>
2. Install Python dependencies
pip install pandas sqlalchemy psycopg2-binary jupyter
3. Start Jupyter Notebook
jupyter notebook
Open Customer_behavior.ipynb and run the cells in order.
4. Configure PostgreSQL
- Install and start PostgreSQL.
- Create a database named customer_behavior (or update the notebook
  to use your database name).
- Update the connection settings in the notebook using your own local
  PostgreSQL credentials.
- Run the notebook cell that loads the prepared data into the
  customer table.
Security: Do not commit database passwords, API keys, or other
secrets to GitHub. Use environment variables or a local configuration
file excluded through .gitignore. If a real password was previously
committed or shared, change it.
5. Run the SQL analysis
Open customer behavior.sql in pgAdmin or another PostgreSQL SQL
client, connect to the database, and execute the queries after the
customer table has been created.
6. Open the Power BI report
Open customer_behavior.pbix in Power BI Desktop. If prompted,
configure the data source to connect to your PostgreSQL database.
